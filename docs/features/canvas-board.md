# Canvas board

The Kanban board is built with Google Sheets' **Canvas** feature (the Gemini
side panel in the Sheet) on top of the **Activity** tab. It is not built by
this codebase: Canvas has no public API, so the board is generated by
prompting Gemini directly in the Sheet, and nothing in `src/` touches it. This
page exists so the design is reproducible without digging through chat history.

## What the board shows

- **Columns from `status`:** To Do, In Progress, Done, and Merged. Issues land in
  the first three (from their `status:` label, or Done once closed); merged PRs
  land in Merged. This is why `status` is derived the way it is in
  `Transformer.js` (see [github-client.md](github-client.md)).
- **Priority** from the `priority:` label, color coded: High red, Medium amber,
  Low green, none grey.
- **Card details:** repo, issue/PR number, title, updated date, issue-or-PR
  badge and state, with a link to the item on GitHub.
- **Filters** for repository and type, and a search box over title, repo and
  number.

## How to (re)generate it

1. Make sure the **Activity** tab has data (run **Repo Pulse → Sync now**).
2. Open the Sheet → Gemini side panel → Canvas, with the Activity tab's data in
   view, and ask for a Kanban board with columns from `status` and cards colored
   by `priority`.
3. Then paste the design prompt below to restyle it. Re-paste it any time you
   want to regenerate the board with the same design language after data model
   changes.

Keep the Activity header row (`repo | type | number | title | state | status |
priority | assignee | updatedAt | url`) as it is; the sync refuses to write if it
was changed, and the board depends on those columns.

## Design prompt used
```
Redesign this Kanban board with a more distinct, less "default AI
dashboard" visual identity. Keep the four status columns and existing
data, but:

- Replace flat priority-dot styling with icon-based priority indicators
  using your available icon set (e.g. Material Symbols) — no emoji
  characters anywhere on the board. Use, for example, a flame icon for
  high priority, a half-filled gauge or circle icon for medium, and a
  leaf/seedling icon for low, paired with the color coding already in
  place
- Increase typographic contrast: bold, larger card titles; smaller,
  muted metadata (repo, date, number)
- Add a slim overall progress bar at the top of the board:
  Done+Merged / Total cards, as a percentage
- Add a compact "Top Contributors" leaderboard panel (top 3, ranked by
  issues closed + PRs merged), using a trophy or medal icon next to
  each rank rather than emoji or plain numbers alone
- Add a streak indicator (a flame or similar momentum icon paired with
  a numeric count) showing consecutive days with at least one closed
  issue or merged PR
- Add a single spotlighted card in a "Needs attention" callout for the
  oldest untouched open item, using an alert/warning icon rather than
  an emoji, separate from the normal columns
- Add small icon badges on individual cards where relevant: a
  "new"-style icon (e.g. a sparkle or new-releases icon) for items
  opened in the last 24h, a warning/alert icon for items untouched 5+
  days, and a bolt/rocket icon for same-day merges
- Use icon glyphs consistently throughout instead of emoji, matching
  whatever icon set is native to Canvas, so the board has one coherent
  visual language rather than mixing icon styles
- Keep information density reasonable — don't crowd every card with
  every badge; only show what applies
```

## Why a custom prompt instead of the Canvas default
The default Canvas-generated board reads as generic — uniform
rounded-corner cards, a single color dot as the only visual
differentiator, no real typographic hierarchy, no sense of momentum or
progress. The custom prompt asks for editorial-style hierarchy instead
of a "generated" aesthetic, plus adds engagement widgets (leaderboard,
streak, spotlight) that aren't part of Canvas's default Kanban
template — chosen specifically for a student/group-project audience
where lightweight gamification (streaks, rankings) is a familiar,
motivating pattern. Icons are used instead of emoji throughout so the
board reads as a designed dashboard rather than a chat-style interface.
